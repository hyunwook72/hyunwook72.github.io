01
보행 주기(Gait Cycle)란 무엇인가?

보행 주기(Gait Cycle)는 한 발의 Heel Contact(발뒤꿈치 닿음)부터 같은 발의 다음 Heel Contact까지의 시간 구간입니다. 보행 분석에서 모든 데이터는 이 주기를 기준으로 정규화됩니다.

보행 주기 구조 (% Gait Cycle)

오른발(Right) 보행 주기
STANCE PHASE (약 60%)
SWING PHASE (약 40%)
0% ▲HC ▲TO 62% 100% ▲HC
HC (Heel Contact) — GRF가 0→양수로 전환되는 순간
TO (Toe Off) — GRF가 양수→0으로 전환되는 순간
⬇️ Stance Phase 0~60%

발이 지면에 닿아 있는 구간. GRF가 0이 아닌 값을 갖는 구간. Loading Response → Mid-Stance → Terminal Stance → Pre-Swing 포함

⬆️ Swing Phase 60~100%

발이 지면에서 떨어져 앞으로 나아가는 구간. GRF = 0인 구간. Initial Swing → Mid-Swing → Terminal Swing 포함

🟢 Heel Contact (HC)

발뒤꿈치가 지면에 처음 닿는 순간. GRF[i]==0 이고 GRF[i+1]>0인 프레임으로 탐지

🔴 Toe Off (TO)

발가락이 지면에서 떨어지는 순간. GRF[i]>0 이고 GRF[i+1]==0인 프레임으로 탐지

💡
왜 GRF로 이벤트를 탐지하는가? 지면반력(GRF, Ground Reaction Force)은 발과 지면 사이의 힘을 측정합니다. 발이 지면에 닿으면 GRF > 0, 공중에 있으면 GRF = 0이 됩니다. 이 성질을 이용하면 매우 정확하게 HC와 TO를 탐지할 수 있습니다.

3
Butterworth 저역통과 필터 적용
GRF 신호에 포함된 고주파 노이즈를 제거합니다. 차단 주파수 10Hz, 4차 Butterworth 필터를 사용합니다. filtfilt는 앞뒤 양방향으로 필터링하여 위상 지연이 없습니다.
Step 3: 저역통과 필터
python
from scipy.signal import butter, filtfilt

def butter_lowpass_filter(data, cutoff=10, fs=1000, order=4):
    """
    Butterworth 저역통과 필터
    cutoff: 차단 주파수 (Hz) - 이 주파수 이상의 성분을 제거
    fs    : 샘플링 주파수 (Hz)
    order : 필터 차수 (높을수록 더 날카로운 제거)
    """
    nyquist = 0.5 * fs          # 나이퀴스트 주파수
    norm_cutoff = cutoff / nyquist  # 정규화된 차단 주파수 (0~1)
    b, a = butter(order, norm_cutoff, btype='low')
    return filtfilt(b, a, data)     # 위상지연 없는 양방향 필터

def apply_filter_to_df(df, cutoff=10, fs=1000, order=4):
    """DataFrame의 모든 수치 열에 필터 적용 (Frame 제외)"""
    filtered_df = df.copy()
    cols = [col for col in filtered_df.columns
            if col not in ("Frame", "Analog_Frame")]
    for col in cols:
        filtered_df[col] = butter_lowpass_filter(filtered_df[col].values,
                                                  cutoff, fs, order)
    return filtered_df

# 적용
force_df = apply_filter_to_df(force_df)

✅

04
Heel Contact(HC) & Toe Off(TO) 이벤트 탐지

전처리된 GRF 데이터에서 이벤트를 탐지합니다. 핵심 아이디어는 간단합니다:

이벤트조건의미
HC GRF[i] == 0 AND GRF[i+1] > 0 공중→지면 접촉: 발이 땅에 닿는 순간
TO GRF[i] > 0 AND GRF[i+1] == 0 지면→공중 이탈: 발이 땅에서 떨어지는 순간
HC/TO 이벤트 탐지 함수
python
def detect_gait_events(grf_x, grf_y, grf_z):
    """
    3축 GRF 데이터로 Heel Contact(HC)와 Toe Off(TO)를 탐지

    Parameters
    ----------
    grf_x, grf_y, grf_z : array-like
        각각 Fx, Fy, Fz 시계열 데이터 (임계값 처리 완료 상태)

    Returns
    -------
    hc : list — Heel Contact 프레임 번호 리스트
    to : list — Toe Off 프레임 번호 리스트
    """
    hc, to = [], []

    for i in range(len(grf_x) - 1):  # i+1을 쓰므로 len-1까지

        # 현재 프레임이 "모두 0" 인지 확인
        zero_now = (grf_x[i] == 0 and
                    grf_y[i] == 0 and
                    grf_z[i] == 0)

        # 다음 프레임이 "모두 0이 아님" 인지 확인
        nonzero_next = (grf_x[i+1] != 0 and
                        grf_y[i+1] != 0 and
                        grf_z[i+1] != 0)

        # HC 탐지: 0 → 양수로 전환
        if zero_now and nonzero_next:
            hc.append(i + 2)  # i+1이 실제 HC 프레임 (1-based)

        # TO 탐지: 양수 → 0으로 전환
        elif (not zero_now) and (not nonzero_next):
            to.append(i + 1)  # i가 실제 TO 프레임 (1-based)

    return hc, to

# 양발에 대해 실행
events = {}
for side in ['R', 'L']:
    x = force_df[f"{side}_Fx"]
    y = force_df[f"{side}_Fy"]
    z = force_df[f"{side}_Fz"]
    hc, to = detect_gait_events(x, y, z)
    events[side] = {'HC': hc, 'TO': to}
    print(f"{side} HC: {hc}")
    print(f"{side} TO: {to}")

HC-TO 쌍(pair) 매칭

탐지된 HC와 TO를 올바르게 짝짓습니다. 각 HC 이후의 첫 번째 TO가 해당 Stance Phase의 끝점입니다.

HC-TO 쌍 매칭 함수
python
def pair_and_filter(hc_list, to_list):
    """
    HC와 TO를 순서대로 짝지어 유효한 (HC, TO) 쌍을 반환
    규칙: 각 HC 이후에 오는 첫 번째 TO와 매칭
    """
    paired = []
    to_idx = 0

    for h in hc_list:
        # h보다 작거나 같은 TO는 건너뜀 (HC보다 앞선 TO는 무효)
        while to_idx < len(to_list) and to_list[to_idx] <= h:
            to_idx += 1

        if to_idx < len(to_list):
            paired.append((h, to_list[to_idx]))  # (HC 프레임, TO 프레임)
            to_idx += 1  # 사용된 TO는 재사용하지 않음

    return paired

# 양발에 대해 매칭 실행
pairs = {
    side: pair_and_filter(events[side]['HC'], events[side]['TO'])
    for side in events
}

print("R pairs:", pairs['R'])
# → [(142, 508), (730, 1096), (1318, 1684), (1906, 2272)]
#     Step1 HC → TO    Step2 HC → TO     ...

Stance Phase를 100프레임으로 정규화

각 stance의 길이가 다르므로, 100프레임으로 시간 정규화하여 비교 분석이 가능하게 합니다.

100프레임 정규화 및 평균 Fz 곡선
python
import matplotlib.pyplot as plt

def normalize_to_100(arr):
    """
    길이가 N인 배열을 100포인트로 선형 보간
    → 모든 stance phase를 같은 길이로 만들어 평균 비교 가능
    """
    return np.interp(
        np.linspace(0, len(arr)-1, 100),  # 새로운 100개 위치
        np.arange(len(arr)),               # 원본 위치
        arr                                   # 원본 값
    )

# 오른발 Fz 정규화 및 평균 계산
fz_cols_R = [col for col in stance_GRF_df.columns
              if col.startswith("R_stance") and col.endswith("Fz")]

fz_raw_R  = [stance_GRF_df[col].dropna().values for col in fz_cols_R]
fz_norm_R = [normalize_to_100(arr) for arr in fz_raw_R]
fz_mean_R = np.mean(fz_norm_R, axis=0)

# 시각화
fig, axes = plt.subplots(1, 2, figsize=(12, 5))

# 왼쪽: 원본 Fz (길이 다름)
for arr in fz_raw_R:
    axes[0].plot(arr, alpha=0.5)
axes[0].set_title("Right Fz - Raw Stance Phases")
axes[0].set_xlabel("Frame")
axes[0].set_ylabel("Fz (N/BW)")

# 오른쪽: 100프레임 정규화 + 평균
for curve in fz_norm_R:
    axes[1].plot(curve, color='gray', alpha=0.3)
axes[1].plot(fz_mean_R, color='red', lw=2, label='Mean')
peak_idx = np.argmax(fz_mean_R)
axes[1].scatter(peak_idx, fz_mean_R[peak_idx],

지금까지 배운 모든 내용을 하나의 파이프라인으로 정리한 완전한 코드입니다.

보행 주기 분할 완전 파이프라인
python
"""
보행 주기(Gait Cycle) 분할 완전 파이프라인
s1_walk_t1.c3d → Stance Phase GRF 추출까지
"""
import ezc3d
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy.signal import butter, filtfilt


# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# 1. 파라미터 설정
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
CUTOFF     = 10     # 저역통과 필터 차단 주파수 (Hz)
FS         = 1000   # 아날로그 샘플링 주파수 (Hz)
THRESHOLD  = 0.03  # GRF 임계값 (N/BW, 이하면 0으로 처리)
FILE_PATH  = "s1_walk_t1.c3d"

# Force Plate 채널 인덱스
FORCE_LABELS = {
    "R_Fx": 48, "R_Fy": 49, "R_Fz": 50,
    "R_Mx": 51, "R_My": 52, "R_Mz": 53,
    "L_Fx": 55, "L_Fy": 56, "L_Fz": 57,
    "L_Mx": 58, "L_My": 59, "L_Mz": 60,
}


# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# 2. 함수 정의
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
def butter_lowpass_filter(data, cutoff=CUTOFF, fs=FS, order=4):
    nyq = 0.5 * fs
    b, a = butter(order, cutoff / nyq, btype='low')
    return filtfilt(b, a, data)

def apply_filter_to_df(df):
    filtered_df = df.copy()
    cols = [c for c in filtered_df.columns if c != "Analog_Frame"]
    for col in cols:
        filtered_df[col] = butter_lowpass_filter(filtered_df[col].values)
    return filtered_df

def detect_gait_events(grf_x, grf_y, grf_z):
    hc, to = [], []
    for i in range(len(grf_x) - 1):
        zero_now     = (grf_x[i]==0 and grf_y[i]==0 and grf_z[i]==0)
        nonzero_next = (grf_x[i+1]!=0 and grf_y[i+1]!=0 and grf_z[i+1]!=0)
        if zero_now and nonzero_next:
            hc.append(i + 2)
        elif (not zero_now) and (not nonzero_next):
            to.append(i + 1)
    return hc, to

def pair_and_filter(hc_list, to_list):
    paired, to_idx = [], 0
    for h in hc_list:
        while to_idx < len(to_list) and to_list[to_idx] <= h:
            to_idx += 1
        if to_idx < len(to_list):
            paired.append((h, to_list[to_idx]))
            to_idx += 1
    return paired

def normalize_to_100(arr):
    return np.interp(
        np.linspace(0, len(arr)-1, 100),
        np.arange(len(arr)), arr
    )


# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# 3. 데이터 로드 및 전처리
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
c3d = ezc3d.c3d(FILE_PATH)
analogs = c3d['data']['analogs']
subframes, n_channels, n_frames = analogs.shape
total_frames = subframes * n_frames
analog_data = analogs.transpose(1, 0, 2).reshape(n_channels, total_frames)

force_df = pd.DataFrame({
    label: analog_data[idx]
    for label, idx in FORCE_LABELS.items()
})
force_df["Analog_Frame"] = np.arange(1, total_frames + 1)

# Fz 부호 반전 (양수화)
force_df["R_Fz"] *= -1
force_df["L_Fz"] *= -1

# 저역통과 필터 적용
force_df = apply_filter_to_df(force_df)

# 임계값 처리
force_df.loc[force_df["R_Fz"] < THRESHOLD, ["R_Fx","R_Fy","R_Fz"]] = 0
force_df.loc[force_df["L_Fz"] < THRESHOLD, ["L_Fx","L_Fy","L_Fz"]] = 0


# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# 4. 보행 이벤트 탐지
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
events = {}
for side in ['R', 'L']:
    hc, to = detect_gait_events(
        force_df[f"{side}_Fx"],
        force_df[f"{side}_Fy"],
        force_df[f"{side}_Fz"]
    )
    events[side] = {'HC': hc, 'TO': to}

pairs = {side: pair_and_filter(events[side]['HC'],
                                events[side]['TO'])
         for side in events}

max_len = max(len(v) for v in pairs.values())
gait_events_df = pd.DataFrame({
    f"{s}_{e}": [p[j] for p in pairs[s]] +
               [None] * (max_len - len(pairs[s]))
    for s in ['R','L'] for j, e in enumerate(['HC','TO'])
}).dropna().astype(int).reset_index(drop=True)

print("✓ 보행 이벤트 탐지 완료:")
print(gait_events_df)


# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# 5. Stance Phase 추출
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
stance_data = {}
for side in ['R', 'L']:
    for i, (hc, to) in enumerate(
        zip(gait_events_df[f"{side}_HC"], gait_events_df[f"{side}_TO"])):
        if pd.notna(hc) and pd.notna(to):
            hc, to = int(hc), int(to)
            for ax in ['Fx', 'Fy', 'Fz']:
                col = f"{side}_{ax}"
                seg = force_df.loc[hc:to, col].reset_index(drop=True)
                stance_data[f"{side}_stance_{i+1}_{ax}"] = seg

stance_GRF_df = pd.DataFrame({k: pd.Series(v)
                                for k, v in stance_data.items()})

print(f"\n✓ Stance Phase 추출 완료: {stance_GRF_df.shape}")

핵심 정리
단계코드왜 이렇게 구현했나?
데이터 로드 ezc3d.c3d() c3d 파일을 계층적 딕셔너리로 파싱. .NET/Visual3D 없이 파이썬에서 직접 접근 가능
Shape 변환 .transpose().reshape() (subframes, ch, frames) → (ch, total_frames)으로 변환해 채널별 처리를 단순화
부호 반전 *= -1 force plate 좌표계에서 Fz가 음수로 기록됨. 양수가 직관적이고 이벤트 탐지에 필수
저역통과 필터 butter + filtfilt filtfilt는 위상지연 없는 양방향 필터. 10Hz cutoff로 노이즈 제거하면서 GRF 패턴 보존
임계값 처리 loc[fz < 0.03] = 0 필터링 후 잔류 노이즈로 인한 오탐지 방지. 0.03 N/BW는 보행 분석 표준 임계값
이벤트 탐지 zero→nonzero → HC 연속된 두 프레임의 GRF 부호 변화를 이용한 단순하고 강건한 알고리즘
쌍 매칭 pair_and_filter() 각 HC 이후 첫 TO를 탐욕적으로 매칭. 이벤트 수 불일치 시 자동으로 불완전한 쌍 제거
정규화 np.interp(linspace) 각 stance duration이 다르므로 100프레임으로 통일 → 피험자 간, 스텝 간 비교 가능
